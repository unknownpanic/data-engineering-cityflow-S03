# Словник даних

Цей документ описує структуру, типи даних та призначення кожної колонки у первинних наборах даних проєкту CityFlow.

## 1. customers.csv
**Опис:** Містить інформацію про клієнтів сервісу. Один рядок відповідає одному унікальному клієнту.

| Поле | Тип (pandas) | Зміст | Роль | Пропуски | Примітки / Проблеми |
|---|---|---|---|---|---|
| `customer_id` | object | Унікальний ідентифікатор клієнта | Первинний ключ | Ні | Рядковий UUID |
| `full_name` | object | Повне ім'я (ПІБ) клієнта | Атрибут | Ні | |
| `email` | object | Електронна адреса | Атрибут | Ні | |
| `phone` | object | Контактний номер телефону | Атрибут | **Так** | Виявлено 5 пропущених значень (NaN) |
| `city` | object | Місто реєстрації/проживання | Атрибут | Ні | |
| `service_zone_id` | object | Ідентифікатор зони обслуговування | Атрибут | Ні | |
| `registered_at` | object | Дата та час реєстрації клієнта | Атрибут | Ні | Формат ISO-8601 (UTC) |
| `customer_status` | object | Поточний статус облікового запису | Атрибут | Ні | Наприклад: active, inactive |

## 3. products.csv
**Опис:** Каталог товарів, які пропонують заклади-партнери. Один рядок відповідає одному товару.

| Поле | Тип (pandas) | Зміст | Роль | Пропуски | Примітки / Проблеми |
|---|---|---|---|---|---|
| `product_id` | object | Унікальний ідентифікатор товару | Первинний ключ | Ні | Рядковий UUID |
| `merchant_id` | object | Ідентифікатор закладу, що продає товар | Зовнішній ключ | Ні | Зв'язок із `merchants.csv` |
| `product_name` | object | Назва товару | Атрибут | Ні | |
| `category` | object | Категорія товару | Атрибут | Ні | |
| `unit_price_uah` | float64 | Вартість однієї одиниці товару в гривнях | Атрибут | Ні | **Проблема:** виявлено значення <= 0 |
| `is_active` | bool/object | Чи доступний товар для замовлення | Атрибут | Ні | |
| `updated_at` | object | Дата та час останнього оновлення ціни/статусу | Атрибут | Ні | Формат ISO-8601 (UTC) |

## 4. orders.csv
**Опис:** Історія замовлень, зроблених клієнтами. Один рядок відповідає одному унікальному замовленню.

| Поле | Тип (pandas) | Зміст | Роль | Пропуски | Примітки / Проблеми |
|---|---|---|---|---|---|
| `order_id` | object | Унікальний ідентифікатор замовлення | Первинний ключ | Ні | Рядковий UUID |
| `customer_id` | object | Ідентифікатор клієнта | Зовнішній ключ | Ні | Зв'язок із `customers.csv` |
| `merchant_id` | object | Ідентифікатор закладу | Зовнішній ключ | Ні | Зв'язок із `merchants.csv` |
| `created_at` | object | Дата та час створення замовлення | Атрибут | Ні | **Проблема:** неіснуючі дати, змішані формати |
| `order_status` | object | Статус замовлення (створено, доставляється, виконано) | Атрибут | Ні | |
| `currency` | object | Валюта оплати | Атрибут | Ні | Зазвичай UAH |
| `subtotal_amount` | float64 | Вартість товарів без урахування доставки | Атрибут | Ні | |
| `delivery_fee` | float64 | Вартість послуг доставки | Атрибут | Ні | |
| `discount_amount` | float64 | Сума застосованої знижки | Атрибут | Ні | |
| `total_amount` | float64 | Загальна сума до сплати (subtotal + delivery - discount) | Атрибут | Ні | |
