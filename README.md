# CityFlow Data Engineering Project (Lab 01)

## Предметна область
CityFlow — це навчальний сервіс міських замовлень і доставки. У цьому проєкті виконується первинне профілювання 4-х джерел даних (клієнти, заклади, товари, замовлення). Студент: S03.

## Структура проєкту
* `data/raw/` — оригінальні CSV-файли (ігноруються Git).
* `data/sample/` — синтетичні зразки даних.
* `docs/` — словник даних, реєстр проблем якості, архітектурна схема.
* `notebooks/` — Jupyter Notebook з кодом профілювання.

## Як запустити
1. Створіть та активуйте віртуальне середовище: `python -m venv .venv`
2. Встановіть залежності: `pip install -r requirements.txt`
3. Помістіть CSV файли в папку `data/raw/`
4. Запустіть `jupyter lab` та відкрийте `notebooks/01_source_profiling.ipynb`.

## Висновки
* Дані містять низку проблем: повні дублікати, відсутні номери телефонів, аномальні ціни та зламані формати дат.
* Структура даних відповідає реляційній моделі (є первинні та зовнішні ключі).
* Наступним етапом має бути очищення (Data Cleansing) перед завантаженням у сховище.
